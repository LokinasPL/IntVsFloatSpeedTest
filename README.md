Auteur : Lokinas Peter Lemire

Date : Mars 2026

Description : Ce projet demandait de comparaer la vitesse de traitement des données en Go selon leur format. On génère donc des énormes tableaux de nombres en Int et en Float, et on calcule combien de temps le programme prend à manipuler différentes portions des tableaux. L'analyse des résultats se trouve dans le fichier pdf.
